## Dotfiles are managed by chezmoi

Most config under `~` (shell, git, jj, editors, terminals, agent config) is generated by chezmoi from `~/.local/share/chezmoi`. Editing the file in `~` directly is wrong: the change is lost or reverted on the next `chezmoi apply`.

Before editing any file under `~`:

1. Run `chezmoi source-path <file>`. If it fails, the file isn't managed; edit it normally.
2. Otherwise edit the source file it prints, then `chezmoi apply <file>` and check the result.
   - A `.tmpl` source is a Go template. Keep the `{{ "{{ }}" }}` logic intact and preview the output with `chezmoi cat <file>`.
   - A `modify_` source merges managed keys over the live file. For `~/.claude/settings.json` and `~/.pi/agent/settings.json`, only keys in `.chezmoitemplates/claude-settings.json` / `pi-settings.json` are managed: change those there. Other keys can be edited in place.
3. Don't commit or push the dotfiles repo unless asked.

Never run `yadm`; it is gone, and its leftover repo recreates stale symlinks.
